# Crestwood School
Premium static primary and secondary school website. Editable HTML, CSS and JavaScript in dist. Published through Sites. Claude Code project skills are in .claude/skills.

The school identity, copy and photographs are illustrative. Replace them with verified school content before public use. Visit plans and checklists are local downloadable text documents. No application or booking is submitted.

Pages: home, our school, primary, secondary, school life, admissions, visit planner and privacy. Client-side hash navigation. Separate reference study at /reference-study.html.

Checks: node --check dist/app.js. Use a static server for local development. The Sites managed cloud-browser preview has no compatible development server for this buildless static project; browser visual QA has not been claimed.
